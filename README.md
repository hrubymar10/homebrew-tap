# homebrew-tap

Homebrew tap for `hrubymar10` formulas.

## Add the tap

```bash
brew tap hrubymar10/tap
brew trust hrubymar10/tap
```

Homebrew requires third-party taps to be trusted before install.

## Install a formula

```bash
brew tap hrubymar10/tap
brew trust hrubymar10/tap
brew install --HEAD hrubymar10/tap/<formula>
```
